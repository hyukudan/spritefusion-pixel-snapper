# Sprite Fusion Pixel Snapper

> **Fork**: This is a fork with additional features. Original: https://github.com/Hugo-Dz/spritefusion-pixel-snapper

**Online version**: https://spritefusion.com/pixel-snapper

A tool to snap pixels to a perfect grid. Designed to fix messy and inconsistent pixel art generated by AI.

## Fork Features

This fork includes the following improvements over the original project:

### Transparency Support (Alpha Channel)

- PNG images with transparency now preserve the alpha channel throughout the entire processing pipeline
- Color quantization operates only on RGB values, keeping the original alpha
- Transparent pixels are ignored during grid edge detection
- Resampling preserves the transparency of the dominant pixel in each cell

### Precise Grid Overlay

- Grid overlay is now drawn using Canvas at the exact cut positions
- Supports non-uniform grids (when the algorithm detects cells of varying sizes)
- Perfect alignment between the visual grid and processed pixels

### Built-in Retro Palettes

Pre-configured palettes for classic systems:
- Game Boy (DMG) - 4 colors
- Game Boy Pocket - 4 colors
- CGA (cyan/magenta) - 4 colors
- CGA Artifact - 4 colors
- Apple II - 6 colors
- EGA 16 - 16 colors
- PICO-8 - 16 colors
- Commodore 64 - 16 colors
- ZX Spectrum - 16 colors
- NES (54 colors)
- Amiga Workbench - 16 colors

### Custom Palette System

- Input custom hex palettes directly (e.g., `#FF00FF #00FFFF`)
- Import palettes from `.txt`, `.gpl`, or `.pal` files
- Export current palette to file
- Palettes are applied before processing to preserve exact colors

### Preset System

- Save complete configurations as reusable presets (k-colors, seed, iterations, palette, resampling mode, etc.)
- Built-in presets for all retro palettes
- Create, apply, and delete custom presets
- Presets persist in localStorage

### Batch Processing

- Queue multiple images for processing
- Process all queued images with the same settings
- Download results as a ZIP file
- Visual queue with clickable thumbnails

### Advanced Comparison Tools

- Side-by-side before/after comparison with slider
- Diff mask showing changed pixels with percentage
- 1:1 loupe/magnifier for detailed inspection
- Swap before/after button

### Resampling Modes

- **Majority vote**: Pick the most common color in each cell
- **Center sample**: Use the center pixel of each cell
- **Edge-aware vote**: Weight pixels by edge detection (configurable weight)

### Target Size Scaling

- Specify target width and/or height
- Aspect ratio is preserved when only one dimension is set
- Uses block voting for non-integer scaling

### Quality Report

After processing, the stats panel shows quality metrics:
- **Grid regularity**: How uniform the detected cell sizes are (100% = perfect grid)
- **Color similarity**: How close the output colors are to the original
- **Pixels changed**: Percentage of pixels modified during processing

### Palette Remapper

- Click any color swatch to open a color picker
- Remap colors in real-time without re-processing
- Reset button to restore original colors
- Changes are applied instantly to the preview and download

### Multi-language Support

- English (EN)
- Spanish (ES)
- French (FR)
- Japanese (JA)

## Why ?

**Current AI image models can't understand grid-based pixel art.**

- Pixel are inconsistent in size and position.
- The grid resolution can drift over time.
- Colors are not tied to a strict palette.

**With Pixel Snapper:**

- ✅ Pixel are snapped to a perfect grid.
- ✅ The grid resolution is consistent and can be scaled to pixel resolution.
- ✅ Colors are tied to a strict, quantized palette.

## Perfect for

- **AI generated pixel art** that needs to be snapped to a grid.
- **Procedural 2D art that doesn't fit a grid** like tilemaps or isometric maps.
- **2D game assets and 3D textures** that need to be perfectly scalable.

## Pixel Snapper comes in two flavors

Requires [Rust](https://www.rust-lang.org/) installed on your machine.

### 💻 CLI

```bash
git clone https://github.com/Hugo-Dz/spritefusion-pixel-snapper.git
cd spritefusion-pixel-snapper
```

```bash
cargo run input.png output.png
```

The command accepts an optional k-colors argument:

```bash
cargo run input.png output.png 16
```

### 🌐 Web (WASM)

```bash
git clone https://github.com/Hugo-Dz/spritefusion-pixel-snapper.git
cd spritefusion-pixel-snapper
```

Build the WASM module:

```bash
wasm-pack build --target web --out-dir pkg --release
```

Then use the WASM module in your project.

### 🖼️ Web playground (local)

- Build the wasm bundle (once): `wasm-pack build --target web --out-dir pkg --release`
- Serve the repo root (`python -m http.server 8000`) and open `http://localhost:8000/web/`
- Drop one or many PNG/JPEG, adjust k-colors/seed/iterations, compare side-by-side or with a slider, toggle grid + zoom, see palette/stats, and download the snapped result (batch to ZIP supported). Everything runs in-browser; no uploads.
